# 마케팅 수신동의 — 동의 문구와 발송 규칙

> 마케팅 수신동의는 문서 한 장이 아니라 **① 동의받는 화면 · ② 발송하는 메시지 · ③ 기록과 운영** 세 덩어리다.

---

## ① 동의받는 화면

### 현재 폼 문구

```
☐ [필수] 개인정보 수집 · 이용에 동의합니다.
        이름 · 휴대폰 · 이메일 / 자료 발송 목적 / 발송 완료 후 6개월 보관
☐ [선택] 다음 도구가 열릴 때 소식 받기
        동의하지 않으셔도 위 자료는 그대로 받으실 수 있어요.
```

### 고칠 것 두 가지

| | 무엇이 문제인가 | 어떻게 |
|---|---|---|
| **필수 동의 안내** | 실제로는 **「지금 제일 손이 많이 가는 업무」(필수)** 와 **「회사 · 직무」(선택)** 도 받고 있는데 안내문에는 빠져 있다 | 항목을 실제와 맞춘다 |
| **선택 동의 문구** | "소식 받기"는 모호한 표현이다. **「광고성 정보」라는 말**과 **전송 매체**가 들어가야 한다 | 아래 문구로 교체 |

### 고친 문구

```
☐ [필수] 개인정보 수집 · 이용에 동의합니다.                       [전문 보기]
        수집 항목 — 이름 · 휴대폰 · 이메일 · 지금 제일 손이 많이 가는 업무
                    (선택) 회사 · 직무
        이용 목적 — 도구 및 자료 발송, 발송 안내
        보유 기간 — 자료 발송 완료 후 6개월

☐ [선택] 이메일 · 문자를 통한 광고성 정보 수신에 동의합니다.        [자세히]
        동의하지 않으셔도 위 자료는 그대로 받으실 수 있어요.
```

- 기본값은 **체크 해제**로 둔다.
- 야간(21시~익일 08시) 수신동의는 **받지 않는다.** 대신 그 시간에 발송하지 않는다.

### 「자세히」에 들어갈 상세 안내

```markdown
### 광고성 정보 수신 동의 안내

**수신 동의 시 받게 되는 정보**
새 도구 공개 소식, 다음 기수 모집 안내, 이커머스 업무 자동화 관련 콘텐츠

**전송 매체**
이메일, 문자메시지(SMS/LMS)

**보유·이용 기간**
동의를 철회하실 때까지

**동의를 거부하실 수 있습니다**
이 동의는 선택 사항입니다. 동의하지 않으셔도 신청하신 도구 8개는 그대로 받으실 수 있습니다.

**철회 방법**
- 발송된 메일 하단의 수신거부 링크
- [[문의 이메일]] 로 요청

**야간 수신**
오후 9시부터 다음 날 오전 8시 사이에는 광고성 정보를 발송하지 않습니다.

**수신 동의 확인**
관련 법령에 따라 동의하신 날부터 2년마다 수신 동의 여부를 확인해 드립니다.
```

## ② 발송하는 메시지

### 무엇이 광고성이고 무엇이 아닌가

| 메시지 | 광고성인가 | 근거 |
|---|---|---|
| ① 신청 직후 — 신청 확인 · 1주차 도구 | **아니다** | 신청한 것을 이행하는 안내 |
| ② 2주차~8주차 — 약속한 도구 발송 | **아니다** | 신청 시 약속한 내용의 이행 |
| ③ 3주차 — "썼다/안 썼다" 답장 요청 | **아니다** | 신청 조건으로 미리 고지한 사항 |
| 8주 종료 후 — 다음 기수 안내, 새 도구 홍보 | **그렇다** | 선택 동의자에게만 발송 |

> **필수 동의만 한 사람에게도 ①②③은 보낼 수 있다.** 약속한 것을 주는 메시지이기 때문이다.
> 8주가 끝난 뒤의 소식은 **[선택] 동의자에게만** 나간다.

### 광고성 메시지 형식

**이메일**

```
제목: (광고) [퇴근이 빨라지는 도구] ○○○

── 본문 ──

(본문 내용)

───────────────────────────
이 메일은 광고성 정보 수신에 동의하신 분께 발송되었습니다.
수신을 원하지 않으시면 아래에서 해지하실 수 있습니다.

수신거부: [[수신거부 링크 또는 회신 안내]]
발신자: 염지은 · [[문의 이메일]]
```

**문자**

```
(광고) [퇴근이 빨라지는 도구]
○○○ 안내드립니다.
무료수신거부 — 문자 광고는 발송하지 않음
```

### 지킬 것

- **"(광고)"를 그대로 쓴다.** `(광 고)` `[AD]` 이모지 대체 — 전부 회피 표기로 위반이다.
- 수신거부에 **연락처 외의 정보를 요구하지 않는다.** 로그인·본인인증 요구는 안 된다.
- 수신거부 **비용을 이용자가 부담하지 않게** 한다.
- **21시~익일 08시 발송 금지.** 현재 수동 발송이므로 발송 시각을 직접 지킨다.

## ③ 기록과 운영

| | 무엇 | 현재 |
|---|---|---|
| **동의 여부 저장** | 선택 동의 체크 값 | 폼에서 받고 있음 |
| **동의 일자 저장** | 언제 동의했는지 | 신청 일시(`created_at`)와 동의 값(`agree_news`)이 같은 행에 저장되어 **신청 일시로 갈음** |
| **철회 처리** | 철회 요청 시 수신 대상에서 제외 | 수동 처리 |
| **2년 재확인** | 동의일로부터 2년마다 확인 | 첫 동의가 **2026-09** 이므로 **2028-09** 에 확인 |

> 현재 신청자 규모에서는 수동 운영으로 충분하다.
> 인원이 늘거나 발송 도구를 도입하면 수신거부 링크와 동의 일자 관리를 자동화한다.
