## 1. 캡션

첫 두 줄이 승부다. 인스타는 그 아래를 접어버린다.
훅과 받는 방법이 접히기 전에 다 보여야 한다.

```
배너 다섯 개 만드는데 오후가 다 갔습니다. 디자인이 아니라 가격 계산하느라요.
받고 싶으시면 댓글에 '도구' 남겨주세요.

이커머스 일을 하다 보면 어렵지도 않은 일에 하루가 갑니다.
배너마다 할인율 계산하고, 주문서 양식 손으로 맞추고, 보고서는 매주 처음부터.

엑셀로 하면 된다고들 하죠. 저도 그렇게 했어요.
그런데 채널이 양식을 한 번 바꾸면 수식이 통째로 깨집니다.

그래서 제가 쓰려고 만든 걸 그대로 드립니다.
가격만 넣으면 할인율까지 계산해서 배너 이미지로 나오는 파일이에요.
설치도 로그인도 없이 더블클릭하면 열립니다. 0원이고요.

댓글에 '도구' 라고 남겨주시면 DM으로 보내드릴게요.

#마케터 #상세페이지 #스마트스토어 #쿠팡 #퇴근

## 2. 댓글에 다는 답글

댓글이 달리면 **답글을 먼저 달고** DM을 보낸다.
답글이 쌓여야 노출이 늘고, 다른 사람이 "나도 달면 주는구나"를 본다.

```
DM으로 보내드렸어요. 확인해보세요!
```

DM이 안 갈 때가 있다. 팔로우하지 않은 계정의 DM은 **요청함**으로 들어가서 못 보는 경우가 많다.
그럴 때는 답글을 이렇게 단다.

```
DM 보내드렸는데 요청함으로 갔을 수 있어요. 확인 부탁드려요!
```

## 3. DM 문구

### 3-1. 기본 — 댓글 달아준 사람에게

```
안녕하세요, 댓글 남겨주셔서 고맙습니다.

말씀드린 배너 생성기예요.
👉 https://work-jiuen.vercel.app/l/kfcb4k

가격만 넣으면 할인율까지 계산해서 배너 이미지로 나옵니다.
설치나 로그인은 없고, 링크 열고 닉네임·이메일만 남기시면
바로 파일을 받으실 수 있어요.

써보시고 어떠셨는지 한두 줄만 남겨주시면 정말 도움이 됩니다.
"이건 썼다" "이건 안 쓰게 되더라" 정도면 충분해요.
```

**왜 이렇게 썼나**

- 첫 줄에 **왜 내가 DM을 받았는지**를 적었다. 광고 DM 으로 오해받지 않게
- 링크를 위쪽에 둔다. 길게 읽고 나서야 링크가 나오면 그 전에 닫는다
- **"닉네임·이메일만"** 을 미리 알린다. 링크를 눌렀는데 폼이 나오면 속았다고 느낀다
- 피드백 요청은 맨 끝에. 받기 전에 조건부터 걸면 문턱이 된다
- 예시 두 줄을 붙였다. "피드백 주세요"만 있으면 뭘 써야 할지 몰라 아무도 안 쓴다

안녕하세요! 댓글 보고 보내드려요.

배너 만들 때 가격 계산 반복하는 거 줄여보려고 만든 파일이에요.
👉 https://work-jiuen.vercel.app/l/kfcb4k

닉네임이랑 이메일만 넣으면 바로 받으실 수 있어요.
써보시고 별로면 별로라고 말씀해주세요. 그게 제일 도움 됩니다.
```

### 3-3. 며칠 뒤 — 신청은 안 한 사람에게

**보낼지 말지는 신중하게.** 안 했다는 건 지금 필요 없다는 뜻일 수 있다.
한 번만 보내고, 답이 없으면 더 보내지 않는다.

```
지난번 보내드린 링크, 혹시 막히는 데 있으셨을까요?

안 여셔도 괜찮습니다. 지금 급한 일이 아니면 나중에 보셔도 돼요.
혹시 링크가 안 열렸던 거면 알려주세요. 다시 보내드릴게요.
```

## 4. 지키는 것

- **콜드 DM 은 보내지 않는다.** 댓글을 단 사람에게만 보낸다.
  상대가 먼저 움직인 뒤에 답하는 구조여야 한다
- **같은 문구를 몰아서 복붙하지 않는다.** 초반에는 손으로 보낸다.
  계정 제한 사례가 있어서, 자동화는 반응 규모가 커진 뒤에 다시 본다
- **팔로우 요구를 붙이지 않는다.** 조건이 둘이 되면 둘 다 안 한다.
  이번 캐러셀의 행동은 **댓글 하나**뿐이다
